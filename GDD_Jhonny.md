# Game Design Document (GDD) - Area do Jhonny

Jhonny, aqui é a sua area para escrevermos as regras base do nosso RPG. Pode escrever como se fosse para um mestre de RPG de mesa ler!

## 1. Atributos Base
*Quais sao os atributos que vao nas fichas dos personagens? (ex: Forca, Labia, Furtividade, Misticismo).*

## 2. A Rolagem de Dados
*Como funciona quando o jogador tenta uma acao dificil? Qual é a matematica? (ex: Dificuldade 7, joga D10s e conta os sucessos).*

## 3. Exemplo Pratico (A Mula Sem Cabeca)
*Escreva aqui um pequeno conto: o jogador tenta convencer a Mula sem Cabeca a ajuda-lo. O que acontece se ele tirar um Sucesso Critico? E o que acontece (Fail Forward) se ele tirar uma Falha Critica?*
